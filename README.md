# OS_Case_Study_CPU_Scheduling
Submission for the OS Case Study

A Scheduling Algorithm Simulation created using Python and pygame

Includes algorithms for FCFS, SFJ, SRT, Round Robin, Priority (Non-Preemptive and Preemptive), and Priority + Round Robin

Requirements:
python3.14


pip install pygame



git clone https://github.com/RenceCLM/OS_Case_Study_CPU_Scheduling.git

cd OS_Case_Study_CPU_Scheduling/

python app.py
